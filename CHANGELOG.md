# Changelog

## 0.1.0 - 2026-09-26

- Release PongBar as a standalone 1D Pong game for Decky Loader.
- Add solo and two player modes across five colour and speed levels.
- Add three early press jokers per player, saved solo streaks and four looping
  LED celebration previews.
- Add SteamUI, Browser Gamepad and on-screen input paths with button learning.
- Add the full-screen 64 x 28 dot matrix interface, procedural sound effects
  and the optional offline CC0 battle theme.
- Add opt-in Steam Controller 2026 HID haptic diagnostics and P1/P2 output
  assignment. Physical vibration remains unconfirmed until tested on hardware.
- Preserve the previous LED frame and release the bar when another writer takes
  ownership.
